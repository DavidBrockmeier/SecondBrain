# SecondBrain

This repository is a context-memory vault: persistent knowledge shared across AI sessions and tools.

## Instructions for AI sessions

- Read the relevant notes here before starting work; treat them as prior context, not disposable output.
- Write durable findings, decisions, and reference material back into this repo as markdown notes with YAML frontmatter, so future sessions (and other agents) inherit them.
- Keep notes self-contained: describe any image or figure in text within the note; store original assets alongside it.
- `references/` holds captured source material. Create sibling folders (architecture, decisions, runbooks, …) as real content warrants — don't scaffold empty structure.

Key note: `references/building-a-second-brain-for-ai.md` — the article this repo's pattern is based on (git-backed Obsidian-style vault as shared MCP-connected memory across Claude, Codex, and other agents).
